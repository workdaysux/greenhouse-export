# About Greenhouse Export

## The Problem

Greenhouse holds your candidate data hostage. Want to export everything to switch ATSes or run your own analysis? They'll make you:
- Pay consulting fees
- Wait weeks for API access
- Manually download resumes one at a time
- Wrestle with undocumented API quirks

All while they focus on redesigning form labels instead of solving user problems.

## The Solution

**Greenhouse Export** is a free, open-source tool that gets YOUR data OUT in 1-2 hours.

Download everything at once:
- All candidates + application history
- Resumes organized by department/role
- CSV ready for any ATS
- Automatic crash recovery (no data loss)

No fees. No waiting. No vendor lock-in.

## Why This Matters

Your recruitment data is valuable. It belongs to you, not Greenhouse. This tool ensures you can:
- **Switch ATSes** without losing history
- **Analyze hiring patterns** independently
- **Migrate to new systems** on your timeline
- **Own your data** without paying Greenhouse's export tax

## How It Works

One command. Interactive setup. Parallel downloads. Done.

```bash
./greenhouse_export    # Download + run
# Enter credentials
# Go grab coffee
# Your data is ready
```

**No Python install needed.** No dependencies. Works on Windows, Mac, Linux.

## Open Source

Built with Python + Bash. MIT licensed. Fully documented. Community-driven.

Questions? Improvements? Open an issue. This tool exists because your data is yours.
